# 3F4-Lab Workbook

Lern- und Nachschlagewerk zu einem 5 × 148 HP Eurorack-Pult: Band 1 Lernpfad, Band 2 Nachschlagewerk mit Modulporträts, Band 3 „Vom Patch zum Stil“ und die Patch-Bibliothek „Klangwege im Pult“.

**Lesen:** https://xof-112.github.io/3f4-lab-workbook/

**Bauen:** `python3 build.py` erzeugt `3f4-lab-workbook.html` und `docs/index.html`. Aufbau, Konventionen und Farbsystem stehen in [LIESMICH.md](LIESMICH.md).
